# 🪨✂️📄 Piedra–Papel–Tijera – Avance AA2 

## 📦 Qué incluye este avance

- `rng.py`: función que genera la jugada de la máquina al azar (distribución uniforme).
- `core.py`: motor de reglas que compara jugadas y devuelve el resultado.
- `demo_cli.py`: demo por consola (usa condicionales y bucle `while`).
- `check_uniformidad.py`: experimento simple para verificar la distribución del RNG.

## 🧰 Requisitos

- Python 3.x

## ▶️ Cómo ejecutar

### Demo simple (AA2)

```bash
python demo_cli.py
```
### Verificar uniformidad (AA2)
```bash
python check_uniformidad.py
```
## 📚 Temas aplicados (Unidad 3)

- Condicionales `if` / `elif` / `else` (comparación de jugadas y mensajes).
- Operadores lógicos y relacionales (reglas de victoria).
- Bucles `while` y `for` + `continue` (demo y verificación de RNG).
- Comentarios y funciones simples.
